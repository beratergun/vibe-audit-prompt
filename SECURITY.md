# Security policy / Güvenlik politikası

This repository distributes instructions and documentation checks. It does not run security scans against applications or provide a hosted audit service. Do not submit application credentials, personal information, private source, or raw vulnerability evidence to public issues or pull requests.

For a sensitive defect in this pack, use GitHub's private vulnerability reporting if enabled on this repository. If it is unavailable, request a private contact channel through a minimal issue without disclosing exploit details or sensitive data. General wording improvements can use ordinary issues and pull requests.

Bu repo talimat ve belge kontrolü dağıtır; uygulamana tarama yapan bir servis değildir. Public issue/PR içine uygulama sırrı, kişisel veri, özel kaynak veya ham açık kanıtı koyma. Hassas bir paket hatasında etkinse GitHub özel güvenlik bildirimini kullan; yoksa ayrıntı paylaşmadan özel iletişim kanalı iste.

No response-time commitment or supported enterprise service is implied. The prompt's safety boundaries and evidence rules are part of the maintained behavior; changes weakening them require explicit review.
